#### Recommended Format
- The project is implemented in the form of a technical workshop-style documentation, following a structured and step-by-step approach. The content is organized similarly to a deployment guide, enabling readers to reproduce the system on AWS.
- The report structure is inspired by the FCAJ workshop template on GitHub, including clear sections such as Overview, Architecture, Implementation Steps, Testing, and Clean-up. The project is presented in a bilingual format (English and Vietnamese) to ensure accessibility and clarity.

#### Tools & Requirements
The project meets the required criteria as follows:
- **Bilingual Content**: All main sections are presented in both English and Vietnamese to ensure clarity and completeness. 
- **Structured Documentation**: The report follows a clear structure including Proposal, Worklog, Workshop, and Evaluation sections. 
- **Architecture Visualization**: System architecture diagrams are created to illustrate the interaction between AWS services (EC2, RDS, S3). 
- **Code Snippets**: Relevant code segments such as database connection (PHP), IAM policies, and configuration steps are included. 
- **Supporting Files**: Deployment-related configurations (e.g., SQL scripts, setup commands) are provided where applicable. 
- **AWS Services Used**: The project utilizes multiple AWS services, including EC2, RDS, and S3, satisfying the requirement of using at least three services.
